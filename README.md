# Programozás feladatgyűjtemény

A [viskillz.inf.unideb.hu/prog](https://viskillz.inf.unideb.hu/prog/) feladatgyűjtemény archivált változata.

Minden feladat külön mappában található (`exercises/<témakör>/<feladat>/`): a `README.md` tartalmazza a leírást, mellette pedig a tesztesetek vannak `.in` (standard bemenet) és `.out` (elvárt standard kimenet) fájlokban.

## Azonosítók

Ahol egy feladatnak több változata van, az azonosító végén lévő betű a bemenet formátumát jelöli:

* `n` – az első sor a tesztesetek számát (`n`) adja meg,
* `t` – a bemenet egy végjelig tart,
* `e` – a bemenet állományvégjelig (EOF) tart.
